# Decision Ledger — v0.3

- JSON-0 remains first canonical workload.
- Encoded Lexical Raster remains canonical raster representation.
- Source bytes remain authoritative and immutable.
- Reference and Recursion remain first-class molecular forms.
- No universal fixed recursion-depth limit.
- JSON CPU parser uses an explicit iterative context stack; native recursive descent is not authoritative runtime state.
- X/Y/Z semantics remain frame-scoped.
- One 3D cast + aligned tri-plane reads remains canonical.
- Plane 1 proposes direction/form intent; Plane 2 constrains admissibility; Plane 3 carries fallback/recovery and recursion governance.
- CPU retains recovery/reauthorization authority.
- Exact bitcodes and binary layouts remain unfrozen.
