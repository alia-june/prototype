# GFX Form Engine / ELR Conversation Bundle

Created: 2026-10-07

This archive binds the current conversation's available textual artifacts into one package.

## Contents
- `CHAT_TRANSCRIPT.md` — visible current-thread transcript reconstructed from the active conversation context.
- `ARCHITECTURE_CANON.md` — consolidated canonical architecture.
- `SCAFFOLD.md` — latest scaffold.
- `logs/` — project ledgers, TODO, AI Error Log, benchmark log, change log.
- `MANIFEST.json` — file hashes, provenance, scope and limitations.
- `PROJECT_STATE.json` — machine-readable snapshot of current locked/provisional decisions.

## Provenance boundary
No conversation files were attached or generated in the current conversation according to the conversation file index at archive time. Therefore no binary files are included.

The archive does not include system/developer instructions, hidden reasoning, private chain-of-thought, or tool payloads.

Where prior assistant output was presented only as chat text, it is preserved through the transcript and consolidated project files rather than falsely represented as an original binary artifact.
