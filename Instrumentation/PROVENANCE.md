## Deliberate exclusions

This export excludes generated bytecode, `__pycache__`, controller SQLite
databases, leases, raw process output, run directories, copied Mill batches,
authority instances, user-specific paths, and unreviewed local evidence.

The public validation summary is derived from retained local reports, but a
report summary is not the original runtime evidence and is not an independent
re-execution.  SHA-256 values demonstrate byte identity of their named inputs;
they do not establish author identity, authority, truth, legal rights, or
semantic compatibility.

The separate [ES-xOSG-0 working example](es-xosg-0/README.md) is a new public
Instrumentation artifact, not a recovered xOSG-0 historical package. Its
synthetic fixtures demonstrate only the explicitly documented receipt adapters.

## Relationship to the repository

The controller package is co-located with [Mill Factory](../mill-factory/README.md)
because it wraps its declared interfaces.  Co-location does not merge the
controller and factory into one runtime, grant a controller permission to alter
Mill source, or admit a shared orchestration protocol.

The repository [MIT license](../docs/xosg/LICENSE) and any notices in the copied source
remain applicable.  Consumers must independently check the current repository
history, source identities, toolchain, authority boundary, and local policies
before using this research tooling.
