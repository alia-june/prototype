# Integrations

External systems are replaceable, referenced capabilities. They are not native authority and are not adopted merely because an instruction file exists.

Every integration remains closed until its own source, version, license, configuration, interface, failure behavior and bounded validation are reviewed and explicitly approved. The common rules are in [`docs/integrations/INTEGRATION_GATE.md`](docs/integrations/INTEGRATION_GATE.md).

## Defined barriers

| Integration | Status | Guide |
| --- | --- | --- |
| Princeton WordNet 3.1 | Payload excluded; acquisition and bounded prior studies recorded | [`WORDNET.md`](docs/integrations/WORDNET.md) |
| External document conversion | Design boundary only; current compatibility adapters remain implemented | [`EXTERNAL_DOCUMENT_CONVERSION.md`](docs/integrations/EXTERNAL_DOCUMENT_CONVERSION.md) |
| GPU backend | Deferred; CPU remains the behavioral reference | [`GPU_BACKEND.md`](docs/integrations/GPU_BACKEND.md) |
| Agentic control | Deferred until the service and other intended work are complete | [`AGENTIC_CONTROL.md`](docs/integrations/AGENTIC_CONTROL.md) |

These guides do not download, install, authorize, start or activate anything.
