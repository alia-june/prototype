# External document conversion barrier

Markdown and referenced JSON state are the prospective native authority. DOCX and other target formats are derived emissions.

## Eject → Transform → Ejection

1. Resolve the complete Markdown/JSON document state.
2. Validate identities, references, assets, profiles and requested transformations.
3. Eject an immutable conversion package.
4. Transform the package through a selected external adapter.
5. Eject the derived artifact and a conversion receipt.

The artifact does not replace the native state. A correction creates a new revision and a new emission.

## Adapter admission requirements

Before admitting an adapter, define its version, acquisition source, license, supported semantic subset, input package, output artifacts, deterministic and nondeterministic behavior, loss diagnostics, asset handling, security boundary, resource limits, failure receipts and removal procedure.

The current M4a Markdown/DOCX adapters remain compatibility implementation. This guide does not remove, replace or certify them, and it does not select an external converter.
