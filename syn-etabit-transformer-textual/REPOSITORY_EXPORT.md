# Repository export

Date: 2026-11-04

This directory is a curated repository variant of the maintained local project. The local originals remain unchanged.

## Included

The export includes active project documents, compatibility service source, tests, examples, contracts, schemas, validation summaries, findings, manifests, bounded research catalogues, the reference-occurrence pilot and inspector, and historical baselines needed to understand the implemented system.

## Excluded

- mutable `.docstream` runtime and harness state;
- Python virtual environments and installed packages;
- Playwright and Chromium installations;
- caches and Python bytecode;
- torture-test SQLite stores;
- the Princeton WordNet archive payload;
- supplied third-party archives and downloaded binaries; and
- the unclassified mosaic image.

External payloads are replaced by integration-barrier instructions. Stable first-party validation evidence is retained where it belongs to the project rather than an installed environment.

## Repository variants

Machine-local usernames and absolute source-machine paths are replaced only in this export. Each changed file receives both an original and exported SHA-256 in the repository export manifest. Historical product names, protocol identifiers, version claims, findings and compatibility surfaces are not normalized.

The dated Phase 1 rebrand record remains historical evidence that `syn` was not expanded by that earlier decision. A later direct user decision defines `syn` as **synthetic**; active export documents reflect the later decision.

## Proof boundary

Hashes prove byte identity for the stated files. They do not prove authenticity, authority, semantic truth, complete privacy, production readiness or independent attestation. Historical test reports remain historical; a repository validation run is reported separately.
