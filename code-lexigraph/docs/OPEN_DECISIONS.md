# Open Decisions

The current artifact is prepared for review as a component in a private hosting repository.

## Repository stewardship

- Any visibility change, additional hosting destinations, or additional remotes.
- License and attribution wording. No license has been selected for this prototype.
- Release and versioning policy beyond the provisional 0.1.0 identifier.
- Supported Python versions and operating systems beyond the environment actually tested.
- Installation packaging and any future continuous-integration workflow.

## Model and construction

- Additional profiles and language backends.
- Complete schema validation and qualification for arbitrary or adversarial bundles.
- Precedence, conflict handling, cyclic relationships, and wider inference rules.
- The boundary between retained code reconstruction and broader code synthesis.
- Independent review of meanings, mappings, and conditional arguments.

## Shared contracts

- Project-specific sentinel encodings and boundary conversion.
- Required survivor, interrupted-mutation, rollback, and continuation policies.
- Continuing-object and version-pinned reference contracts, retention, and failure behavior.
- Numeric expansion/resource budgets and their counting rules.
- Formal process-qualification axes and required evidence.

The local immutable-text survivor and finite validation cases do not settle these wider questions. Future changes require a concrete scope and the applicable human approval.
