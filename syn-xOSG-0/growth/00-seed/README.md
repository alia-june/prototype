# 00 — Seed

## Question
What is the smallest structure that can coordinate work without pretending that a request is already an execution?

## Seed contents
- machine-readable description;
- technical logical instrumentation;
- normal operating prompt;
- natural-language compatibility layer;
- NOTES / TODO / ERROR-LOG / AGENDA / ROADMAP;
- verification before delivery;
- explicit capability boundary.

## Seed invariant

```text
REQUEST != COMPLETION
```

## Why stop here?
Because the seed should be small enough that later growth can be explained. A seed that already contains every later mechanism cannot teach where those mechanisms came from.

## Growth pressure
The seed describes state but does not yet make that state operational or durable.

That pressure produces **01 — Actualization**.
