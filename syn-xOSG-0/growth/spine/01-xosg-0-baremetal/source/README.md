# xOSG-0
## Expert Overlay System Gestalt — Version Bare-Metal 0

Portable reference artifact for the synthetic orchestration workspace.

## Four-layer architecture

1. Machine Description JSON
2. Technical Logical Instrumentation
3. Normal Text Operating Prompt
4. Natural-Language Compatibility Layer

The four layers represent the same workflow at different abstraction levels. Lower layers may translate or simplify higher-layer rules, but must not silently change them.

## Core workflow

INTAKE → DECOMPOSE → ASSIGN → EXECUTE → RECONCILE → VERIFY → DELIVER → LOG

## Five registers

- NOTES
- TODO
- ERROR-LOG
- AGENDA
- ROADMAP

## Operational boundary

xOSG-0 is a conversational/workflow overlay. It does not claim to modify the underlying model, system instructions, software configuration, privileges, or unavailable capabilities. Simulated specialist roles are abstractions unless actual tools or people are used.
