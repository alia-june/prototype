# 03 — Learning Layer

## Pressure
Fixing bugs individually does not explain what the system is learning.

## Added learning stack

```text
ERROR LOGS
 -> LESSONS
 -> PATTERNS
 -> ANTIPATTERNS
 -> LOGIC
 -> META-LOGIC
 -> ANALYSIS
 -> META-ANALYSIS
```

## Promotion rule
A lesson does not become architecture merely because it was written down.

Promotion requires evidence, an invariant, failure-mode review, tests where applicable, and a recorded decision.

## New pressure
The system now needs disciplined categories for evidence, action, mutation, and promotion.

That produces **04 — Operator Kernel**.
