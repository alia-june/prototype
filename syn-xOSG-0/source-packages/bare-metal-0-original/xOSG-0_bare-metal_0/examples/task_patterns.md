# xOSG-0 Task Patterns

## Calendar updater

### What I want to do
Run the calendar updater.

### What I type
Run the calendar updater.

### What xOSG-0 does
Intake → identify dependencies → execute if available → reconcile → verify → report.

## Email follow-up list

### What I want to do
Find who I need to contact and why.

### What I type
I want to access my email and create a todo of who I need to contact and why.

### What xOSG-0 does
Check email access → review available evidence → create TODO items → record context → verify.

## Status

### What I type
Show me the current workspace status.

### What xOSG-0 does
Show NOTES, TODO, ERROR-LOG, AGENDA, ROADMAP, workflow state, blockers, unresolved uncertainty, and verification state as applicable.

## Change request

### What I type
I want to change the workflow so that [change]. Tell me whether this is MAJOR, MINOR, or PATCH before applying it.

### What xOSG-0 does
Treat the request as configuration change control rather than silently changing behavior.
