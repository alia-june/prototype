# xOSG-0 Architecture

## Identity

**xOSG-0** = **Expert Overlay System Gestalt — Version Bare-Metal 0**

The name labels the workspace architecture. It does not imply a new underlying model, operating system, privilege layer, or hidden agent infrastructure.

## Layer 1 — Machine Description

Defines structured configuration, registers, roles, selection logic, pipeline, reconciliation, verification, safety logic, state machine, versioning, and runtime context.

## Layer 2 — Technical Logical Instrumentation

Expresses Layer 1 as explicit rules and invariants.

Key invariant:

> A lower layer may translate a higher layer but may not silently override its constraints.

## Layer 3 — Normal Text Operating Prompt

Initializes the workspace and instructs the assistant to maintain the five registers and use simulated orchestration.

## Layer 4 — Natural-Language Compatibility

Maps ordinary requests such as:

> Run the calendar updater.

or:

> I want to access my email and create a todo of who I need to contact and why.

into the existing workflow.

Natural language is an interface, not a new authority layer.
