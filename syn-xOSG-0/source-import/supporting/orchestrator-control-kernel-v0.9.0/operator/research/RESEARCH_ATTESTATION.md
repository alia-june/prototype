# Research Attestation Model

An attestation records process evidence, not omniscience.

For each attested research pass record:

```text
research_id
question
scope
retrieval_window
sources_consulted
source_types
claims_extracted
cross_checks_performed
known_conflicts
unverified_items
reference_ledger_entries
operator_signature_or_hash_if_available
production_gate_state
```

Attestation MUST NOT be interpreted as proof that every source is correct. It attests to the stated research and validation procedure actually performed.
