# Prompt Summary — Deterministic Offload / Gestalt Hypervisor

The Operator objective is to minimize semantic model contact for tasks that can be performed deterministically, while preserving the Operator/Orchestrator boundary and active control-stack constraints.

The resulting design adds:
- Gestalt Hypervisor;
- meta-orchestration system;
- data-touch policy;
- deterministic self-task catalog;
- attestation pipeline;
- synchronous task graph;
- minimized evidence artifacts.
