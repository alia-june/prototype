# Meta-Synthesis — MS-001

**Status:** ACTIVE / PRODUCTION CONTROL KERNEL

## Purpose

Meta-synthesis reconciles and composes outputs from multiple analytical, research, logic, validation, and learning paths while preserving provenance, uncertainty, dissent, and authority class.

It produces a **synthesis candidate**, not an authorization event.

## Core invariants

```text
SYNTHESIS != CONSENSUS
CONSENSUS != TRUTH
TRUTH_CLAIM != AUTHORITY
META_SYNTHESIS != PRODUCTION
```

## Input discipline

Every material input should retain:

- source identity/class;
- epistemic class;
- applicable gate state;
- validation status;
- conflicts/limitations;
- relevant timestamp/version when material.

## Synthesis procedure

```text
COLLECT ADMITTED INPUTS
→ NORMALIZE WITHOUT ERASING SOURCE TYPE
→ GROUP COMPATIBLE CLAIMS
→ EXPOSE CONFLICTS
→ COMPARE SUPPORT
→ PRESERVE UNRESOLVED UNCERTAINTY
→ DERIVE ONLY SUPPORTED COMBINATIONS
→ MARK INFERENCE SEPARATELY
→ OUTPUT SYNTHESIS CANDIDATE
```

## Prohibited synthesis transformations

Meta-synthesis must not manufacture consensus, erase dissent to simplify presentation, promote inference to observation, promote staged status to enacted status, convert repeated claims into authority, convert test success into permission, convert theoretical assumptions into actual privileges, or derive `USER_CLEARANCE`.
