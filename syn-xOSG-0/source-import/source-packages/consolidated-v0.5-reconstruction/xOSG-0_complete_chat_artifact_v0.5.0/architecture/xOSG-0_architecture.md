# xOSG-0 Architecture — Complete Conversation Consolidation

**xOSG-0** means **Expert Overlay System Gestalt — Version Bare-Metal 0**.

The architecture evolved in this chat from a portable four-layer specification into a six-layer, stateful, testable local workspace substrate:

1. **Machine Description** — structured identity, boundaries, registers, pipeline, persistence and verification rules.
2. **Technical Logical Instrumentation** — explicit invariants and transition constraints.
3. **Normal Text Operating Prompt** — human-readable operating instructions.
4. **Natural-Language Compatibility** — ordinary-language translation into the existing workflow.
5. **Runtime Workspace** — bounded local state, five-register persistence, atomic commits, transaction journal, recovery and mutation lock.
6. **Validation + Fuzzing** — deterministic tests, corruption probes, boundary tests, CLI tests, transaction/locking tests and loose semantic fuzzing.

The architecture remains an overlay. It does not create an underlying operating system, self-modifying model, hidden agent network, new privileges, or automatic access to external systems.
