# Semantic Symbol Interpreter — v0.2.1 repository distribution

This distribution contains the v0.2.1 interpreter, validation harness, and synthetic fixture suite, with a repository README and architecture guide. The engine, harness, schemas, tests, and fixture files are retained from v0.2.1. The benchmark and validation documents summarize the recorded release run; they do not report a new full benchmark.

The distribution leaves out private working records, original snapshots, and host-specific diagnostics. Temporary candidate paths in recorded benchmark data use a neutral filename. `manifest.json` lists the distributed files and their hashes, excluding the manifest itself. See [README.md](README.md) to run the prototype.

## Project name

Semantic Symbol Interpreter was previously distributed as SSMI. This edition updates the public name while keeping internal identifiers, fixture IDs, schemas, and recorded benchmark results compatible with v0.2.1.
